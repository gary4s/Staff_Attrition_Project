# HR Analytics Dashboard – Attrition Insights Project
Overview
This project explores employee attrition using an interactive HR analytics dashboard built to surface the key drivers behind workforce turnover. The goal was to transform raw HR data into clear, actionable insights that support evidence‑based decision‑making for HR leaders, workforce planners, and organisational strategists.

The dashboard provides a multi‑dimensional view of attrition, enabling users to slice the data by demographic, behavioural, and job‑related factors. It highlights not only what the attrition rate is, but why employees may be leaving — and which groups are most at risk.

# Key Features
# Attrition Summary
A high‑level overview showing the overall attrition rate based on user‑selected filters. This acts as the entry point for deeper exploration.

# Demographic Breakdown
Interactive visuals allow users to compare attrition across:
  Gender
  Job roles
  Departments
  Education and education fields

These views help identify whether specific groups experience disproportionate turnover.
# Employment & Behavioural Factors
The dashboard highlights how job‑related characteristics influence attrition, including:
  Business travel frequency
  Overtime patterns
  Work‑life balance ratings
  Job satisfaction levels
  Distance from home

These insights help organisations understand which working conditions correlate with higher risk.

# Compensation Insights
Attrition is analysed across monthly income bands, revealing how salary levels relate to employee retention.

Employee attrition is a costly challenge for organisations. By identifying the factors most strongly associated with turnover, HR teams can:
  Target retention initiatives
  Improve employee experience
  Reduce recruitment and training costs
  Strengthen workforce stability
This dashboard provides a practical, data‑driven foundation for those decisions.
